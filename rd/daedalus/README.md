# Daedalus Onboard Engineering

This folder is the project documentation boundary for the Daedalus mothership's R&D program.

The established Daedalus runtime modules currently remain at their existing repository paths (including `daedalus-rd.js`, `daedalus-rd.css`, `vigil-rd-labs.js`, and the Daedalus integration modules). They are intentionally not moved in this change, to avoid breaking existing script references, workbenches, or deployment behavior.

Future Daedalus-specific source, models, and assets can be added here in a separately tested migration.
