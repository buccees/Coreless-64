# VIGIL R&D

Research projects are organized as separate workspaces. Keep project-specific code, documentation, models, and assets inside their own folder.

## Project folders

- [Daedalus](./daedalus/README.md) — mothership onboard engineering and recovered spacecraft systems.
- [PLAGUE](./plague/README.md) — independent nanoscale technology and instrument-limited observation research.

The R&D page in `index.html` is the directory entry point. Each project is opened from its own folder card.

## Compatibility rule

Existing Daedalus runtime files remain at their established repository paths for now. Do not relocate or rename them as part of unrelated PLAGUE work; existing script references and deployment assumptions depend on those paths.
