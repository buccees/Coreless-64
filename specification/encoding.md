# Coreless-64 Binary Encoding v0.1\n\nStatus: Draft — executable binary definition\n\nCoreless-64 v0.1 uses fixed 32-bit base instructions. This is intentional: the first decoder should be simple enough to map directly to RTL while leaving a clean extension path.\n\n## Instruction word\nAll instructions are 4 bytes, 4-byte aligned, and little-endian in memory. PC points to the first byte. Sequential PC is PC + 4.\n\n## Primary opcode\n| Value | Family |\n|---:|---|\n| 0x00 | ALUR |\n| 0x01 | ALUI |\n| 0x02 | LOAD |\n| 0x03 | STORE |\n| 0x04 | BRANCH |\n| 0x05 | JUMP |\n| 0x06 | SYSTEM |\n| 0x07 | ATOMIC |\n| 0x08 | FP |\n| 0x09 | VECTOR |\n| 0x0A | MATRIX |\n| 0x0B | CRYPTO |\n| 0x0C | VM |\n| 0x0D-0x1E | RESERVED |\n| 0x1F | ESCAPE |\n\n## R-format\nBits 31:27 primary, 26:22 rd, 21:17 rs1, 16:12 rs2, 11:5 reserved, 4:0 funct. Reserved bits must be zero.\n\n## I-format\nBits 31:27 primary, 26:22 rd, 21:17 rs1, 16:12 funct, 11:0 signed immediate.\n\nALUI operations use this format. The 12-bit immediate is sign-extended.\n\n## Load format\nBits 31:27 primary, 26:22 rd, 21:17 rs1, 16:14 width, 13:0 signed immediate.\nWidth: 0=8-bit signed, 1=16-bit signed, 2=32-bit signed, 3=64-bit, 4=8-bit unsigned, 5=16-bit unsigned, 6=32-bit unsigned.\n\n## Store format\nBits 31:27 primary, 26:22 rs2, 21:17 rs1, 16:14 width, 13:0 signed immediate.\n\n## Branch format\nBits 31:27 primary, 26:22 rs1, 21:17 rs2, 16:12 funct, 11:0 signed byte offset.\nBranch target = PC + sign-extended offset. Target must be 4-byte aligned.\n\n## Jump format\nDirect J and CALL use: bits 31:27 primary, 26:22 rd, 21:17 reserved, 16:12 funct, 11:0 signed offset. For these forms the 12-bit offset is sign-extended.\nRegister-indirect JR and CALLR use: bits 31:27 primary, 26:22 rd, 21:17 rs1, 16:12 funct, 11:0 signed offset. Target = R[rs1] + sign-extended offset.\nRET uses funct 0x04 with all register/offset fields zero.\n\n## System format\nBits 31:27 primary, 26:22 rd, 21:17 rs1, 16:0 operand. The operation defines which fields are used.\n\n## Operation assignments\nALUR funct: 0x00 ADD, 0x01 SUB, 0x02 MUL, 0x03 DIV, 0x04 UDIV, 0x05 REM, 0x06 UREM, 0x07 AND, 0x08 OR, 0x09 XOR, 0x0A NOT, 0x0B SHL, 0x0C SHR, 0x0D SAR, 0x0E ROL, 0x0F ROR, 0x10 SLT, 0x11 SLTU, 0x12 SEQ, 0x13 SNE, 0x14 NEG.\nALUI funct: 0x00 ADDI, 0x01 SUBI, 0x02 ANDI, 0x03 ORI, 0x04 XORI.\nBRANCH funct: 0x00 BEQ, 0x01 BNE, 0x02 BLT, 0x03 BGE, 0x04 BLTU, 0x05 BGEU.\nJUMP funct: 0x00 J, 0x01 CALL, 0x02 JR, 0x03 CALLR, 0x04 RET.\nSYSTEM funct: 0x00 NOP, 0x01 HALT, 0x02 WAIT, 0x03 TRAP, 0x04 RETX, 0x05 FENCE, 0x06 TLBFLUSH, 0x07 TLBFLUSHVA, 0x08 READCSR, 0x09 WRITECSR.\n\n## Illegal encodings\nUndefined primary/function combinations, nonzero reserved fields, unsupported extensions, and privilege violations are illegal. Illegal instructions do not retire.\n\n## Decoder contract\nThe decoder produces: instruction class, operation, rd, rs1, rs2, immediate, privilege requirement, and memory-access type.\n\n## Extension rule\nESCAPE 0x1F is reserved. Extended encodings will be added only after the base decoder and conformance tests are stable.
