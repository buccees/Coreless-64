# Coreless-64 Binary Encoding v0.1\n\nStatus: Draft — executable binary definition\n\nCoreless-64 v0.1 uses fixed 32-bit base instructions. This is intentional: the first decoder should be simple enough to map directly to RTL while still leaving a clean extension path.\n\n## Instruction word\n\nAll instructions are 4 bytes, 4-byte aligned, and little-endian in memory. PC points to the first byte. Sequential PC is PC + 4.\n\n## Register fields\n\nrd, rs1, and rs2 are each 5 bits and encode R0-R31.\n\n## Primary opcode\n\n| Value | Family |\n|---:|---|\n| 0x00 | ALUR |\n| 0x01 | ALUI |\n| 0x02 | LOAD |\n| 0x03 | STORE |\n| 0x04 | BRANCH |\n| 0x05 | JUMP |\n| 0x06 | SYSTEM |\n| 0x07 | ATOMIC |\n| 0x08 | FP |\n| 0x09 | VECTOR |\n| 0x0A | MATRIX |\n| 0x0B | CRYPTO |\n| 0x0C | VM |\n| 0x0D-0x1E | RESERVED |\n| 0x1F | ESCAPE |\n\n## R-format\n\nBits 31:27 primary, 26:22 rd, 21:17 rs1, 16:12 rs2, 11:5 reserved, 4:0 funct.\nReserved bits must be zero.\n\n## I-format\n\nBits 31:27 primary, 26:22 rd, 21:17 rs1, 16:0 signed immediate.\n\n## S-format\n\nBits 31:27 primary, 26:22 rs2, 21:17 rs1, 16:12 width, 11:0 signed immediate.\n\nStore widths: 0=8 bit, 1=16 bit, 2=32 bit, 3=64 bit.\n\n## B-format\n\nBits 31:27 primary, 26:22 rs1, 21:17 rs2, 16:12 funct, 11:0 offset fragment.\n\nBranch offset is a signed byte displacement and must be 4-byte aligned.\n\n## J-format\n\nBits 31:27 primary, 26:22 rd, 21:17 rs1, 16:12 funct, 11:0 immediate low portion.\n\nDirect jump/call displacement is signed and 4-byte aligned. The exact immediate reconstruction is reserved for the final decoder table; no implementation may guess it.\n\n## Base operation assignments\n\nALUR funct: 0x00 ADD, 0x01 SUB, 0x02 MUL, 0x03 DIV, 0x04 UDIV, 0x05 REM, 0x06 UREM, 0x07 AND, 0x08 OR, 0x09 XOR, 0x0A NOT, 0x0B SHL, 0x0C SHR, 0x0D SAR, 0x0E ROL, 0x0F ROR, 0x10 SLT, 0x11 SLTU, 0x12 SEQ, 0x13 SNE, 0x14 NEG.\n\nALUI funct: 0x00 ADDI, 0x01 SUBI, 0x02 ANDI, 0x03 ORI, 0x04 XORI.\n\nLOAD width: 0=LD8, 1=LD16, 2=LD32, 3=LD64, 4=LD8U, 5=LD16U, 6=LD32U.\n\nBRANCH funct: 0x00 BEQ, 0x01 BNE, 0x02 BLT, 0x03 BGE, 0x04 BLTU, 0x05 BGEU.\n\nJUMP funct: 0x00 J, 0x01 CALL, 0x02 JR, 0x03 CALLR, 0x04 RET.\n\nSYSTEM funct: 0x00 NOP, 0x01 HALT, 0x02 WAIT, 0x03 TRAP, 0x04 RETX, 0x05 FENCE, 0x06 TLBFLUSH, 0x07 TLBFLUSHVA, 0x08 READCSR, 0x09 WRITECSR.\n\n## Illegal encodings\n\nUndefined primary/function combinations, nonzero reserved fields, unsupported extensions, and privilege violations are illegal. Illegal instructions do not retire.\n\n## Decoder contract\n\nThe hardware/reference decoder produces: instruction class, operation, rd, rs1, rs2, immediate, privilege requirement, and memory-access type.\n\n## Extension rule\n\nESCAPE 0x1F is reserved. Extended encodings will be added only after the base decoder and conformance tests are stable. This prevents the hardware foundation from becoming dependent on an unfinished variable-length format.
